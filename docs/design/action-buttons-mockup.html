Question actions — 5 styles

Static mockup for the four Questions-screen actions (Reveal, Skip, Next, Main Menu) so they stop resembling the answer pills. Each card shows the current answer buttons on top and the scheme's action cluster underneath. Nothing committed, no app files touched. Reply with a number — or a mix.

=Current look

Skip is pixel-identical to the answer pills (it inherits the global button style), Main Menu is the white-outline pill, Reveal/Next reuse the big green launch pill. This is what the 5 schemes below have to beat.
